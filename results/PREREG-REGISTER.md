# Pre-registration — register test v2 (paper-v5 §2.5)

Written 2026-10-13 20:22:18 IST, before any v2 code was written or run.

## Why the v1 test could not work
In OLMo-2 and Tulu-3 chat templates the role markers (<|user|>, <|assistant|>) are ordinary text tokens,
not special IDs (Tulu adds only <pad>). Special-token mass therefore cannot see the register in these
families; the v1 null is uninformative by construction, not merely weak.

## Claim under test (§2.5)
Alignment shifts mass along a learned, largely context-free register direction, not by reweighting
toward the reference model's own likely tokens.

## Measures (per delta, per position i, on the same token set S_i)
- psi_i     = corr(delta_i[S_i], logp_ref_i[S_i])                        (typicality geometry; as before)
- rho_reg_i = corr(delta_i[S_i], g_-p[S_i]) where g_-p = mean delta over all positions of the OTHER 35
              prompts (leave-one-prompt-out; no in-sample leakage)       (register geometry)
- rho_partial_i = partial corr of delta_i with g_-p controlling for logp_ref_i
Regions S_i: top-50 of ref, plausible (ref p > 1e-6), plus prob-weighted variants. Bootstrap over prompts.

## Arms
A. Chat-templated: each prompt wrapped with the aligned model's chat template + generation prompt; identical
   token IDs fed to all four stages (base included); assistant-start position. Also: EOS mass there.
B. Continuation positions: 6 samples x 32 tokens per prompt (T=1.0, top-p 0.95, seed 20261012) generated by
   the BASE model, raw prompt; teacher-forced through all four stages so contexts are paired. All 32 positions.
   Also reports entropy-share by stage averaged over continuation positions (prompt-major: mean within
   prompt, bootstrap over the 36 prompts).

## Predictions
Register hypothesis supported if, for base->SFT in arm B (plausible region):
  rho_reg 95% CI excludes 0, AND rho_reg > psi (paired bootstrap CI of the difference excludes 0),
  AND rho_partial CI excludes 0.
Not supported if rho_reg CI includes 0 or rho_reg <= psi.
Secondary (no strong prior): same test on SFT->DPO at 7B/8B, where DPO carries 26-41% of entropy loss;
arm A direction expected to match arm B. Any outcome is reported, including a second null.

## Models
OLMo-2-0425-1B (development run), OLMo-2-1124-7B, Tulu-3-8B (base = meta-llama/Llama-3.1-8B).
Runs share the GPU with the 13B queue via logs/gpu.lock; never two heavy models resident at once.
