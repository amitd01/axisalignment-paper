## Rejected suggestions

- Gemini's §6.3 manifold explanation: speculative, cannot be tested, contradicts §6.3.
- Gemini's abstract: calls the 1B result degenerate when it is a null (1.04×).
- Gemini's judge script: uses an older Claude model and a coarse 1–5 scale. A modern judge model is a fine idea, but the script would need rebuilding.
- NotebookLM's scripts: one builds an 8 GB diagonal matrix, uses wrong regression weights and omits the shared component.
- 70B+ scale: out of scope (limitation 8).
